# The Barakah Circle — صفحة العطاء الشهري والسنوي

صفحة واحدة لـ Human Appeal USA عن التبرع المتكرر، على شكل **٤ أسئلة سريعة
→ ملخص → سلة الموقع**. مبنية بنفس كلاسات وألوان وخطوط الموقع الحالي،
وجاهزة للرفع على Umbraco.

---

## 1. الاسم المقترح

### ✅ الترشيح الأول: **The Barakah Circle**

- **اسم الصفحة (URL):** `humanappealusa.org/the-barakah-circle`
- **العنوان الرئيسي (H1):** *Give every month. Grow every year.*
- **الجملة التعريفية:** *Four quick questions and your sadaqah keeps working
  — through Ramadan, through emergencies, and through every ordinary day in
  between.*

**ليه الاسم ده؟**

| بيكمّل عيلة موجودة | عندكم فعلًا **The Jummah Club** (أسبوعي). نفس بنية الاسم → بيبان إنهم برنامجين من نفس البيت |

## 2. التجربة — ٤ أسئلة بس

مفيش قوائم طويلة ولا كروت كتير. المتبرع بيجاوب سؤال في الشاشة، وأول ما
يختار بينتقل تلقائيًا للسؤال اللي بعده، وشريط التقدّم بيتحرك.

```
س1  تحب تتبرع كل قد إيه؟        →  كل شهر / مرة في السنة
س2  عايز تدعم إيه؟              →  ٦ صناديق
س3  دي زكاة ولا صدقة؟           →  زكاة / صدقة / عام
س4  المبلغ؟                     →  ٣ مبالغ مقترحة + مبلغ حر
──────────────────────────────────────────────────────
ملخص  "Here's your gift"  →  زرار Continue to basket  →  سلة الموقع
```

**تفاصيل بتفرق:**

- **السؤال الثالث بيتخطّى لوحده** لما الصندوق نفسه محدِّد نوعه
  (Zakat Fund زكاة دايمًا، Clean Water صدقة جارية). يبقى ٣ أسئلة بدل ٤.
- **المبالغ بتتحدّث تلقائيًا** حسب الإيقاع: تختار "سنوي" → `$50` بتبقى `$600`.
- **الملخص فيه أزرار "Change"** لأي إجابة من غير ما يبدأ من الأول.
- **زرار Back** في كل خطوة.
- **من غير JavaScript** الأسئلة بتظهر كلها تحت بعض والصفحة تفضل مقروءة.

## 4. شكل الصفحة

سبع أقسام بس:

```
1  Hero            صورة عريضة + بوكس أبيض (نفس بلوك الموقع)
2  ★ الأسئلة       كارت أبيض في النص + شريط تقدّم
3  ليه المتكرر؟     حديث + ٣ أسباب
4  اقتباس          آية على الباترن البنفسجي بتاعكم
5  FAQ             ٦ أسئلة
6  Trust bar       Charity Navigator + Candid + EIN + التليفون
7  CTA أخير        "Make it a habit, not a decision."
```

**قسم واحد بس جديد** (رقم 2). الباقي بلوكات موجودة عندكم فعلًا.

### الاتساق مع الموقع

القيم دي مسحوبة مباشرة من `theme.css` الحيّ عندكم — مش تخمين:

| العنصر | القيمة |
|---|---|
| البنفسجي الأساسي | `#662d91` |
| البنفسجي الغامق | `#32195c` |
| البنفسجي الفاتح | `#7332aa` / `#ede7f2` |
| أحمر الـ CTA | `#e10032` |
| الأخضر | `#00b37d` |
| الخط | DIN Next / DIN Next Arabic |
| الأزرار | `border-radius: 8px` · uppercase · bold |

والصفحة بتستخدم كلاسات الموقع نفسها (`.wrap` `.h1` `.button--primary`
`.pull-quote` `.list-to-grid-text` …) — أول ما تترفع هتورث كل حاجة
تلقائيًا، وأي تعديل مستقبلي في الثيم هيطبّق عليها.

مفيش أي مكتبة خارجية — لا jQuery ولا غيرها.

## 5. الملفات

```
umbraco/
  page-body.html              ← ده اللي بيتلصق في Umbraco
  recurring-giving-block.css  ← يترفع على /css/
  recurring-giving-block.js   ← يترفع على /js/
  UPLOAD-GUIDE.md             ← خطوات الرفع + مفاتيح CRM + checklist

handoff/
  barakah-circle.zip          ← ★ الحزمة اللي تبعتها لفريق الموقع
  README.md                   ← دليل إنجليزي للمطوّرين (جوّه الـzip كمان)

preview/
  live-simulation.html        ← ★ الصفحة جوّه هيدر وفوتر وثيم الموقع الحقيقي
  index.html                  ← معاينة خفيفة (بدون شكل الموقع)
  assets/live/                ← نسخة مخزّنة من CSS وخطوط الموقع
  …                           ← ملفات معاينة فقط، متترفعش

build-preview.py              ← يبني المعاينة الخفيفة
build-live-preview.py         ← يبني محاكاة الموقع الحقيقي
build-handoff.py              ← يبني حزمة التسليم
```

### الحزمة اللي تبعتها لفريق الموقع

`handoff/barakah-circle.zip` — جوّاها بالظبط اللي محتاجينه ومفيش زيادة:

```
barakah-circle/
  README.md                    دليل إنجليزي: الخطوات + الـIDs + checklist
  page-body.html               يتلصق في Umbraco
  recurring-giving-block.css   يترفع على /css/
  recurring-giving-block.js    يترفع على /js/
  preview.html                 معاينة أوفلاين يفتحوها قبل ما يلمسوا حاجة
```

**ابدأ من:** `preview/live-simulation.html` — افتحه في المتصفح وجرّب التجربة
كاملة. ده مش موك-أب: ده `page-body.html` بالظبط جوّه ماركب وستايل الموقع
الحقيقي، فاللي هتشوفه هو اللي Umbraco هيعرضه.

بعد أي تعديل:

```bash
python3 build-preview.py && python3 build-live-preview.py
```

## 6. مطلوب قبل النشر

1. **٧ قيم `donationItemId`** من الـ CRM — مكتوب مكانها `REPLACE_ME`.
   الصفحة مش هتشتغل من غيرها.
2. تأكيد المطوّر على `action` الفورم (حاليًا `action=""` زي Jummah Club).
3. موافقة فريق البرامج على المبالغ المقترحة وتصنيف الزكاة.
4. صورة نهائية لصندوق كفالة اليتيم (الحالية صورة غزة، مؤقتة).

التفاصيل الكاملة في `umbraco/UPLOAD-GUIDE.md`.
